# Final Project Report Template

## 1. Abstract

Write a concise summary of the project: problem, approach, prototype,
results, and key takeaway.

## 2. Introduction

2.1 Background & Motivation

Explain the context and the problem.

2.2 Project Goals

State the objectives of your project.

## 3. Project Description & Workflow

3.1 Problem Statement

Describe the problem you are addressing.

3.2 Overview of the Proposed Solution

Provide an overview of your solution and operating principles.

3.3 Workflow Diagram / System Flow

Insert a diagram showing data flow, sensors, control logic, etc.

## 4. Prototype Development --- Hardware

Datasheet and description of the load of choice

Describe hardware choices, ESP32 wiring, sensors used, rationale, and
calibration steps.

(feel free to add pictures/screenshots)

## 5. Prototype Development --- Software

External API? What are the data sources? Ecc...

Explain software architecture, data handling, control logic. Include
block diagrams or pseudocode if it helps explaining.

(feel free to add pictures/screenshots)

## 6. Testing and validation iterations (optional)

Testing/calibration of the sensors/hypothesis valdation procedures...

## 7. Results

Present findings, performance metrics, savings, potential improvements,
visualizations, ...

## 8. Conclusion

Summarize accomplishments, main takeaways, strengths, weaknesses...

## 9. References

List datasheets, tutorials, libraries, research papers, and other
resources used.

## 10. Appendices (Optional)

Include schematics, extended data, code snippets, ...

**IMPORTANT**: The guidelines are only general and common sense always
wins.

No need to write long paragraphs, OK to keep it brief and schematic.

Around 20 pages but if you can explain more with less, even better.
